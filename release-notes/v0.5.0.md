# v0.5.0

One new action: the `profiles` tool imports PenguinBurner auto-uv results
directly, closing the loop the tuner leaves open (it advertises LACT
exports but ships no export CLI).

## Added

**`profiles import`.**
Point `file` at a PenguinBurner `auto-uv-profile-*.json` and get a LACT
profile with the tuned VF offsets (each validated: index 0..126, offset
±1000 MHz) plus the tuned power cap. The profile is written through
`create_profile` with a `provided` base, so the live GPU config is
untouched — pass `apply: true` to also set it current. `name` defaults to
the file's `profile_id`, `gpu_id` defaults to the sole NVIDIA GPU
(explicit `gpu_id` required when several exist). Bad files, empty plans,
and out-of-range values fail loudly with no daemon write.

Out of scope on purpose, like the manual export before it: PenguinBurner's
clock lock (LACT cannot lock NVIDIA clocks — the flattened curve does the
job) and its parametric fan curve (LACT fan settings left alone).

## Verified live

- `python3 lact_mcp.py --test` green on 2 GPUs (RTX 3080 + Radeon iGPU):
  import of a synthetic 127-point plan asserts profile content (1 offset +
  300 W cap), asserts the live config is byte-identical before/after, then
  deletes the throwaway profile; missing-file import refused.
- Real-world use: the tuned `balanced` profile (850 mV / 1862 MHz, 69
  offsets, 320 W) and the `efficiency`-tier one (781 mV / 1680 MHz, 78
  offsets, 225 W) both imported with matching offset counts and caps,
  live config untouched, current profile unchanged.

## Install

```jsonc
{
  "mcp": {
    "lact": { "type": "local", "command": ["python3", "/path/to/lact-mcp/lact_mcp.py"] }
  }
}
```

Quit and relaunch opencode. Asset `lact_mcp.py` is attached to this release;
Python 3.10+, stdlib only, no dependencies.
