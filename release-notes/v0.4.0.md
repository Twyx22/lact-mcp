# v0.4.0

A small feature release: the `profiles` tool can now manage the full profile
lifecycle, so a rename (create-clone + set + delete) no longer needs raw
`daemon_query` calls with hand-shaped socket schemas.

## Added

**`profiles create` / `profiles delete`.**
`create` makes an empty profile, or clones an existing one with
`"from": "<profile>"` (verified live against `lactd`: clone carries fan
settings, power cap, and power mode). `delete` removes a profile but refuses
the current one — set another profile first, so the daemon is never left
without an active profile. Profile writes apply immediately (no 5 s
confirm window involved).

## Verified live

- `python3 lact_mcp.py --test` green on 2 GPUs (RTX 3080 + Radeon iGPU),
  including a create → clone → delete round-trip on throwaway profiles and
  the delete-current refusal; `lact cli profile list` shows no leftovers.
- MCP stdio smoke: `tools/call profiles create {"from": "efficiency"}` then
  `delete` round-trips cleanly.
- Real-world use: renamed a live `a` profile to `efficiency` (225 W cap,
  Adaptive, custom fan curve), applied as default, old profile removed.

## Install

```jsonc
{
  "mcp": {
    "lact": { "type": "local", "command": ["python3", "/path/to/lact-mcp/lact_mcp.py"] }
  }
}
```

Quit and relaunch opencode. Asset `lact_mcp.py` is attached to this release;
Python 3.10+, stdlib only, no dependencies.
