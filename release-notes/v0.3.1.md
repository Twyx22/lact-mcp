# v0.3.1 — Harmattan

The dry wind that sweeps the dust off the gauges.

A bug-hunt release: four defects found by scanning the server against a live
`lactd` (RTX 3080 + Radeon iGPU, lact 0.10.1). No new tool, no behaviour
change for the happy paths — only the wrong or lying ones.

## Fixed

**`daemon_query` writes to `set_gpu_config` were silently reverted.**
The tool promises that GPU-config writes (`set_*`) auto-confirm so lactd
does not roll them back after ~5 s. `set_gpu_config` was missing from the
hand-maintained confirm list, so the write was staged, reported `ok`, and
then quietly undone. The list is now a rule — any `set_*` command plus
`batch_set_clocks_value` — so a new daemon command cannot be forgotten.

**`daemon_query` rejected an integer gpu id.**
`{"command": "device_info", "args": {"id": 1}}` died on
`invalid type: integer, expected a borrowed string` while `"1"` worked.
Both are accepted now, and both resolve to the full LACT id.

**`voltage get` claimed offsets that were not applied.**
The `vf offsets now` line dumped the distinct `freq_offset` values of the
driver's stock curve (which is `freq - base_freq`, not a user setting), so a
completely default config printed a `-270..+105 MHz` spread and looked
undervolted. It now reports the applied per-point offsets, i.e.
`vf offsets applied: none (stock curve)` when nothing is set.

**A hung `lact cli` returned a JSON-RPC internal error.**
Timeouts (`subprocess.TimeoutExpired`) escaped the tool wrapper and surfaced
as `-32603` instead of the `isError` tool result used by every other
failure.

**Docstring drift.** The module header listed 10 tools and omitted
`voltage`; there are 11.

## Verified live

- Idempotent `set_gpu_config` sent through `daemon_query` survives the 5 s
  revert window (auto-confirm reached).
- `{"id": 1}` resolves, `voltage get` reports `none (stock curve)`, a forced
  15 s `lact` timeout returns a clean tool error.
- `python3 lact_mcp.py --test` green on 2 GPUs; CI smoke test asserts the
  11-tool registry.
- GPU left stock: power cap 320 W, fan curve untouched.

## Install

```jsonc
{
  "mcp": {
    "lact": { "type": "local", "command": ["python3", "/path/to/lact-mcp/lact_mcp.py"] }
  }
}
```

Quit and relaunch opencode. Asset `lact_mcp.py` is attached to this release;
Python 3.10+, stdlib only, no dependencies.
